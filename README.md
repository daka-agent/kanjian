## 关于游戏

**「看见」** 是一款互动叙事游戏。你扮演一名大学班主任，在日常工作中——批改作业、上课、回复消息——逐渐发现一位学生（林小晴）正在经历心理健康困扰。

游戏时长约 **15-20 分钟**，覆盖一周五天。每个信号面前你都要做出选择：问问她？观察一下？请同学帮忙？这些选择将影响你们之间的信任关系，最终导向四种不同的结局。

**核心传达：每个人都可以成为支持者。**

不需要成为心理专家，不需要想好完美的措辞。一句「最近还好吗」、一个安静的陪伴、一条「我在这」——这些微小的行动，可能就是另一个人生命里唯一的光。

## 游戏特色

- **18 个碎片化信号** — 来自作业、课堂、同学转达、私聊消息，拼凑学生的真实状态
- **55 个选择分支** — 每个信号三种策略，没有唯一「正确」的答案
- **隐藏的信任值** — 不显示数字，通过语气和回应感知关系变化
- **10 段内心独白** — 第一人称视角，揭示「被看见」的另一面
- **4 种结局** — 信任/迟到发现/错过/过度，没有彻底失败
- **公益资源衔接** — 结局页直达心理援助热线和实操建议
- **6 步新手引导** — 贴合叙事语境的「入职简报」式引导
- **结局画廊** — 收集已解锁的结局，记录你的选择旅程

## 设计理念

### 「信号」不是「症状」
刻意避免心理学术语。信号（未交作业、撤回消息、潦草的周记）是任何班主任都可能遇到的日常异常——玩家只需判断「好像不对劲」，不需做出诊断。

### 所有结局都不是「失败」
即使在信任最低的结局，系统仍然说「注意到，就还来得及」。没有人应该因为「来不及了」而感到二次伤害。

### 一键之遥的现实帮助
游戏结束不是终点。结局页直接提供中国心理援助热线及给教师/家长/支持者的实操建议。
